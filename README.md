# 灵梦 · AI 辅助的系统工程案例（摘要页）

> 完整案例与质量门禁工具箱在受控访问仓库里。本页说明它是什么、包含什么，以及如何申请访问。

本页用于展示 AI 辅助的系统工程与质量方法：一个人用 AI 把一套无线神经接口从概念推进到仿真方案，并把每个数字、每个结论、每一次自我纠错都做成可追源、可复核的产物。

## 两件事

1. **案例研究**：一套双向、闭环、无线的神经接口概念方案。供电、编码、计算尽量放在体外，植入侧尽量少。核心结论是：电极端口的仿真可用电压约为检波阈值的一成（约 20 dB [S]）；缺口能否闭合、后续优化路径怎么选，要等芯片 SDK 与完整芯片设计完成、联合仿真跑通后才能确定。
2. **质量门禁**：三个零依赖脚本（来源标签检查、脱敏检查、跨文件审计）、19 个单元测试、21 个样例文件。一份"故意有缺陷"的样例能稳定复现 5 项问题，CI 在每次提交时自动执行这组检查。

## 公开文档

两篇不依赖内部参数的方法文档，可直接阅读：

- [验证计划](case-study/03_validation_plan.md)：从纸面到在体的七级阶梯，什么算证据、什么不算证据，预注册判据，以及为什么芯片设计、全波 EDA 与联合仿真是 AI 替代不了的人工关键路径。
- [状态与路线](case-study/04_status_roadmap.md)：已经验证到哪一级、哪些尚未验证、卡在哪些条件，以及分阶段的验证条件清单。

## 它不是什么

- 不是原型、不是实测、不是流片；没有自有的测量或人体数据，引用的测量与人体数据来自公开资料和文献。
- 不承诺系统可复现：可复现的是门禁与样例；系统本身需要项目内部的模型、日志与设计环境。
- 只做民用研究，不含军用、NDA 或涉密内容。
